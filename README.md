# Opportunity OS

A frontend concept for a student opportunity dashboard: one place to explore scholarships, internships, research programmes, hackathons, exchanges, and startup challenges.

This repository is a UI/UX experiment rather than a live opportunity directory. The cards and dates in the demo are illustrative, so they should not be used as application information.

## What the prototype explores

- Search and category filters for a mixed opportunity feed
- Clear funding, location, and deadline signals
- A compact application-pipeline view
- Responsive card layouts for desktop and mobile
- Evidence-first UI patterns that keep source verification visible

## Running it

Open `index.html` directly in a browser. The prototype has no backend, accounts, analytics, or personal data.

## Status
